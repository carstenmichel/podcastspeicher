# README notes (must not forget)

## ⚠️ Highlight prominently in the final README

**Feeds are truncated — late subscribers can only get what the feed still lists.**
Most podcast hosts cap their RSS feed at roughly the last 20–50 episodes.
If you register a podcast late, episodes that the feed no longer offers are
**unreachable via the feed**. This app can only mirror what the stream still
serves. State this limitation prominently (callout box / warning section) in
the README, near the top, so users set the right expectations before adding
shows.
